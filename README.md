## ⚙️ DevOps Principles

| Principle | What I Value |
| --- | --- |
| **Automation First** | 반복 작업을 자동화하고 사람이 실수할 수 있는 지점을 줄입니다. |
| **Everything as Code** | 인프라와 설정을 코드로 관리하고 변경 이력을 추적합니다. |
| **Observability** | 메트릭, 로그, 트레이스를 기반으로 시스템을 이해합니다. |
| **Continuous Improvement** | 작은 변경을 자주 배포하고 피드백을 빠르게 반영합니다. |
| **Reliability & Security** | 안정성과 보안을 개발 및 운영 과정의 기본 조건으로 다룹니다. |

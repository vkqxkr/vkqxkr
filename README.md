Hi! I’m a DevOps engineer who builds stable, repeatable infrastructure and makes delivery faster through automation.<br>
I care about cloud-native systems, practical developer experience, observability, and secure operations. 🚀

#### ☁️ On the cloud & infrastructure side,

I build and manage both AWS and on-premises infrastructure with Terraform. I value reusable modules, environment-aware configuration, and infrastructure that can be reproduced with confidence.

#### 📦 On the container & delivery side,

I build Python backend services with Django and FastAPI, and work with Docker, Kubernetes, Helm, GitHub Actions, Jenkins, and Argo CD to create reliable CI/CD and GitOps workflows—from build and test to deployment and rollback.

#### 📊 On the reliability & operations side,

I use Prometheus, Grafana, Alloy, Mimir, Tempo, Elastic Stack, and Loki to make systems observable. I also work across networking, security, databases, and Linux to keep services reliable and operationally simple.
